# Resultados

Os arquivos CSV gerados por `python -m experiment.runner` são gravados neste
diretório. Preserve cada CSV juntamente com a data, o commit do código e as
versões do ambiente usadas na execução.

O arquivo `coleta_manual.csv` complementa a coleta automática com tempo de
adaptação, arquivos e linhas modificadas. Preencha uma linha imediatamente após
cada combinação de estratégia e cenário para reduzir erros de memória.
